官方皮肤速览 · 同骨不同皮

同一份 DOM 模板、不同 token 表——皮肤能改变多少 = 参数化覆盖多广。霓虹机甲演示 comp.banner 组件槽位（全局扁平卡 + 横幅独立霓虹）。

原型 ↔ 产品映射：SKINS/BASE 常量 = skin.json token 表；resolve() = lib/skin_repository.dart 的确定性合并器（优先级：动态取色 > 自定义 overlay > 皮肤 > 默认，纯黑压制深色面）；apply() = 快照注入（颜色轨 Dart 落色 / 形态轨 ctx.skin → tokens.js）；导出/导入 = L3 文件出入口。环境开关（明暗/密度/字号/动态取色）与皮肤正交，不进皮肤包。D-52：落地禁逐卡 blur，玻璃 = 半透明 + 描边 + 棱线 + 背景整层模糊；本页 backdrop-filter 仅为浏览器演示效果。
